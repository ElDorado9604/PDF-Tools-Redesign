How it works. This page loads MuPDF compiled to WebAssembly and renders each page in your browser's memory — the same engine desktop PDF tools use, just running locally instead of on a server. All pages are bundled into a single ZIP file, built entirely in-browser. First load pulls down about 10 MB of engine files; after that it works from cache.
