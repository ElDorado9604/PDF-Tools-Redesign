100% on-device

PDF Tools

Private, offline PDF utilities that run entirely in your browser. Your files never leave this device.

🔓
Unlock PDF
Remove an existing password from a protected PDF.
 🔒
Lock PDF
Add AES-256 password protection to a PDF.
 🖼️
PDF → Images
Export every page as PNG or JPEG.
 📎
Merge PDFs
Combine multiple files into one.
 📷
Images → PDF
Combine photos into a single PDF.
 🗜️
Compress PDF
Shrink a PDF’s file size.
 📄
Code → PDF
Turn source or text files into a clean PDF.
How it works. These tools load MuPDF compiled to WebAssembly and process your file in the browser’s memory — the same engine desktop PDF apps use, just running locally. First load downloads about 10 MB of engine files; after that everything works from cache.
